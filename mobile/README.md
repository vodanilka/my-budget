# My budget — Expo Go

Нативное приложение той же модели Budget VF.

```bash
cd mobile
npm install
npx expo start --tunnel --port 47821
```

В списке Projects Expo Go проект **не появится**, пока вы его не откроете по QR или `exp://` ссылке (это не опубликованный проект аккаунта).

1. Установите [Expo Go](https://apps.apple.com/app/expo-go/id982107779).
2. Отсканируйте QR из терминала или откройте `exp://` / страницу `/_expo/loading?platform=ios`.
3. После первого открытия My budget останется в недавних.

Песочница банков: `user_good` / `pass_good`.
